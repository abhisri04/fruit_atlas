# UPLYFA — Product Vision

Read this before building any new feature or changing an existing one.

## Mission

Help people **experience more in life**: try hobbies (small or big), explore new places and things, keep a record of all of it, and share it with the people they care about.

Uplyfa is a **record of a life well lived**, not a set of separate features.

## Core principle: personal first, social on top

Build in this order. Every feature must work at the earlier stages before it depends on the later ones.

1. **Solo (core):** tracking, India Passport, streaks, milestones, and share cards for Instagram and WhatsApp.
2. **Light social:** add friends, see their milestones ("Riya tried pottery"), react with a cheer. No comments, no open feed.
3. **Together:** shared challenges (e.g. "Try 150 Easy Hobbies with 3 friends"), group trips that stamp everyone's passport, "do this together" invites. This is where Uplyfa should stand out.
4. **Community (later):** public profiles, local hobby groups, discovering like-minded people.

## Rules for every feature

- **Works with zero friends.** A user with no connections must still get full value. Social features are optional add-ons, never requirements.
- **Encourage, don't compare.** Use cheers, shared goals and personal progress. No leaderboards or rankings that create pressure.
- **Logging takes seconds.** One tap, an optional photo, done. If it feels like homework, simplify it.
- **Celebrate what's added, not what's missed.** A broken streak should never feel like failure. Prefer gentle recovery ("pick up where you left off") over loss.
- **Make the record feel valuable.** Capture photos, places, dates and "firsts" so users want to look back at it and show it off.
- **Sharing is a product, not a button.** Share outputs (cards, passport pages, recaps) should be beautiful and say something about the person, not just dump data. Include subtle "Made with Uplyfa" branding.
- **Private by default.** Nothing is shared or visible to others unless the user chooses.
- **Retention without guilt.** Keep people coming back with monthly recaps, "this day last year" moments and gentle nudges, not pressure.

## When reworking older features

Check each existing feature (Explore India, Daily Discovery, fruit catalogue, Yoga Atlas, Books, India Passport, Hobbies, Try 150 Easy Hobbies, My Hobbies, Games, Scent & Perfume, Garden & Plants, Collecting, Trips) against the rules above:

- Does it feed into the user's personal life record?
- Can its progress be turned into a shareable card or milestone?
- Could it later support doing it together with friends?
- Does any part of it create comparison pressure or guilt that should be softened?
